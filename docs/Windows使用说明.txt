Selection Copilot — Windows 便携版

1. 将压缩包完整解压到一个固定目录，双击 SelectionCopilot.exe。
   不需要安装 Python。请保留同目录的 _internal 文件夹，不能单独移动 exe。
2. 首次运行会打开设置，填写 API 地址、API Key、模型名称并保存。
   如果本机已有保存的设置，会沿用；API Key 没有内置在分发包中。
3. 在软件中拖动、双击或用常见键盘操作选中文字，会弹出工具栏。
   优先读取 UI Automation 真实选区；PPT 编辑模式使用原生文本选区接口。
   也可以选中文字后按 Alt+Q，再选择翻译、解释或其他操作。
   如果仍不能取词，可手动复制后从托盘选择“使用剪贴板文字”。
   默认对微信启用受控复制兼容；可在设置中选择仅快捷键、指定应用或禁用复制。
   已明确保存的旧复制策略保持不变；UIA 选区事件本身不会触发复制。
   终端和常见 IDE 宿主不使用模拟复制，避免触发中断。
4. 关闭设置窗口后仍会在系统托盘运行。托盘图标可能在右下角的隐藏图标中。
   右键蓝色 SC 图标可打开设置、暂停自动划词或退出。
   再次双击 exe 会打开已有实例的设置，不会重复运行。

配置：%LOCALAPPDATA%\SelectionCopilot\settings.json
日志：%LOCALAPPDATA%\SelectionCopilot\logs\app.log（自动轮转）
可选：复制 .env.example 为 exe 同目录下的 .env，并填入自己的配置。
配置优先级：保存的设置 > 系统环境变量 > exe 同目录 .env > 默认值。
不要分享自己的 .env 或 settings.json，其中可能包含 API Key。

命令行选项：
  SelectionCopilot.exe --settings   打开设置
  SelectionCopilot.exe --quit       退出当前用户的已有实例

运行平台：Windows 10/11 x64。此版本未做代码签名。
自动划词取决于目标控件的无障碍接口，不支持图片中的文字识别。
复制兼容只在 UIA 不支持时尝试一次；无选区、密码框、错误和超时不会自动复制。
未知剪贴板内容格式及超过 16 MiB 的备份会跳过兼容复制。
OLE 所有权与传输元数据不作为内容重放；已支持的实际内容会备份，并在复制完成后
按序列号和所有者检查恢复。其他应用的新写入会保留；同应用并发复制仍有识别边界。
朗读使用 Windows 自带的 SAPI 语音；可用语言取决于本机安装的语音。
联网功能需要有效的 API 配置。退出程序后可以删除整个解压目录；
用户设置和日志仍保留在上述本地目录中。
